# Портфолио Арины Аксеновой

Сайт на чистом HTML, без сборки. Публикуется через Cloudflare Pages из этого репозитория на GitHub.

## Где что лежит

| Путь | Что там |
|---|---|
| `js/content.js` | **Все тексты, проекты, ролики и контакты.** Править почти всегда нужно только его. |
| `media/` | Картинки и видео, разложены по разделам сайта |
| `files/` | Сюда класть PDF с резюме |
| `index.html` | Каркас страницы и заголовки разделов |
| `css/style.css` | Дизайн |
| `js/main.js` | Логика (плеер, карусели, видео). Не трогать. |

## Первая публикация

1. Загрузите в репозиторий **содержимое** папки (не саму папку): на GitHub — Add file → Upload files, перетащите все файлы и папки, затем Commit changes. Файл `index.html` должен оказаться в корне репозитория.
2. Cloudflare → Workers & Pages → Create application → Pages → Connect to Git → выберите этот репозиторий.
3. В настройках сборки: Framework preset — None, Build command — пусто, Build output directory — пусто (если поле обязательно, впишите `/`). Save and Deploy.
4. Когда сайт получит адрес (например `https://portfolio.pages.dev`), откройте `index.html` на GitHub и в двух строках замените `SITE-ADDRESS` на этот адрес. Это нужно для красивого превью ссылки в LinkedIn и Telegram.

## Как править

Любая правка на GitHub (значок карандаша → Commit changes) через минуту появляется на сайте.

**Изменить текст.** Откройте `js/content.js`, найдите текст, поправьте внутри кавычек.

**Добавить проект в карусель.**
1. Положите обложку 16:9 в `media/projects/` (Add file → Upload files).
2. В `content.js` в списке `projects` скопируйте любой блок `{ … },` и поменяйте название, текст, ссылку на YouTube и путь к обложке.

**Добавить свою генерацию.** Видео и его обложку (кадр .jpg) положите в `media/generations/`, затем в `content.js` в списке `generations` добавьте строку по образцу. Первая в списке показывается крупно.

**Подключить резюме.** Положите PDF в `files/`, в `content.js` впишите путь в поле `cv`, например `"files/Arina_Aksenova_CV.pdf"`. Кнопки Download CV появятся сами.

## Про видео

- Полные ролики — только ссылкой на YouTube, на сайте они открываются в плеере поверх страницы.
- Короткие лупы лежат в `media/`. Каждый файл должен весить меньше 25 MB (лимит Cloudflare), а лучше 1–2 MB: MP4 (H.264), без звука, 10–15 секунд, по ширине не больше 1280 px. Сжать можно в бесплатной программе HandBrake.
- Имена файлов — латиницей, без пробелов: `my-new-scene.mp4`.

## Если что-то сломалось

Если после правки на сайте появилась красная плашка — в `content.js` пропала кавычка или запятая. Откройте файл на GitHub → History → последнюю правку и сравните, или нажмите Revert, чтобы откатить её целиком.
